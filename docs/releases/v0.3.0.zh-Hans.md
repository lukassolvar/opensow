OpenSOW 0.3.0 让启动器告诉你有哪些变化、何时有更新可用，并修复了玩家在战斗中发现的两个问题。如果你已经安装了 0.2.0，启动器会自动提供这次更新。

## 新功能

- **版本号和更新标记。** 启动器侧边栏在每个页面都显示版本号。有新版本发布时，图标上会出现跳动的标记，版本行显示新的版本号；点击即可前往更新。
- **主页上的新内容。** 一张卡片让你一眼看到当前版本的变化。有更新可用时，它会显示新版本的变化和安装按钮。说明提供英语、斯洛伐克语、捷克语和中文。
- **GitHub 链接。** 侧边栏链接到项目页面，你可以在那里报告问题、关注开发进展。
- **更流畅的启动器。** 页面淡入并滑动到位，按钮会响应鼠标，设置齿轮会旋转。没有动画时，启动器仍然不占用处理器。

## 修复

- **防空炮塔开火时播放发射音效**，与原版一致；以前只能听到命中声。
- **放大时火焰保持流畅。** 近距离观看时，火焰喷射器会让游戏卡顿；现在它的光晕绘制速度快了数倍。
- **更简洁的启动器页面：** 去掉了主页的大图标和标语以及游戏页面的副标题，Warmonger 条目显示游戏全名。
