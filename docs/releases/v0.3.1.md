OpenSOW 0.3.1 is a hotfix for the campaign. If you already have 0.3.0, the launcher offers this update by itself.

## Fixed

- **Winning a loaded mission counts.** A campaign mission you continued from a savegame (quick load or Load Game) showed the victory screens, but the campaign map still had the land open and nothing new unlocked. Now the land is passed and the next one opens, as in the original, in both State of War and Warmonger. A land you already won this way has to be played once more.

## Known limitations

- No network play yet; skirmish is against the computer.
- Polish, Hungarian and Russian copies of the game run with English menus.
- A few details are not yet checked against the original: how a building looks while it is being destroyed, and some of Warmonger's mission-number rules.
- Unit pathfinding uses a simplified version of the original's grid, so units can occasionally take a slightly different path.

Please [report what you find](https://github.com/lukassolvar/opensow/issues/new/choose). OpenSOW is an unofficial fan project, not affiliated with the original developers or publishers.
