OpenSOW 0.4.2 加入了原版的 Ctrl / Alt 攻擊鍵、Warmonger 自己的作弊短語，存檔也會保留視角書籤。如果你已經安裝了 0.4.1，啟動器會自動提供這次更新。

## 新功能

- **按住 Ctrl 或 Alt 攻擊，與原版一致。** 按住其中任一鍵點擊敵方建築，會下達持續攻擊命令，單位會一直攻擊直到建築倒下；一般點擊只會讓它們前往一次。按住該鍵還能攻擊自己的單位和建築，攻擊游標也會隨之左右傾斜。
- **Warmonger 自己的作弊短語。** Warmonger 戰役現在檢查其原版的短語，包括只有 Warmonger 才有的那個作弊。在兩個戰役中，輸入的作弊都會像原版一樣顯示為一行聊天。
- **存檔保留視角書籤。** 數字鍵盤書籤以及 Tab 和 H 的繼續位置會被儲存，讀檔時恢復。每個任務開始時都帶有原版的九個預設書籤，因此每個數字鍵盤鍵從一開始就能移動視角。
