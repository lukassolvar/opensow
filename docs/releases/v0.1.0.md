The first public beta of OpenSOW: State of War, the 2001 real-time strategy game, running natively on macOS, Windows
and Linux with the data from your own copy.

This is a beta: both campaigns, skirmish and the map editor are playable, but expect rough edges;
please [report what you find](https://github.com/lukassolvar/opensow/issues/new/choose).

## What's in it

- **Both campaigns in one game.** Switch between State of War and Warmonger on the campaign map; each keeps its own
  progress. Warmonger is optional.
- **Skirmish against the computer** on all 14 multiplayer maps of both games, or on your own: set both sides' credits,
  research, air forces and turrets, pick Easy, Normal, Hard or Brutal, and collect a star for each level you beat.
- **Map editor in the game.** Any of the game's terrains, buildings, turrets and units for either side, win rules
  (destroy the HQ, destroy everything, escort a convoy) and timers. Your maps appear on the skirmish screen.
- **Faithful to the original.** Game rules, the computer's play and the file formats are decoded from the original
  executable and checked against it; savegames are written in the original format.
- **Today's screens.** Any resolution up to 4K, drawn on the graphics card (Metal, Vulkan or DirectX 12) at a steady
  60 frames per second, with the processor as a fallback.
- **Enhancements you can switch off** on a second options page: sharper textures when zoomed in, soft shadows,
  explosion glow, better sound, turret range while placing, and map zoom.
- **A launcher** that finds your games, keeps the settings in one place, offers five interface languages (English,
  Slovak, Czech and Chinese in simplified and traditional characters) and updates itself.

## Getting started

1. **You need your own copy of State of War**, for example from Steam. OpenSOW contains no game data. On macOS and
   Linux, Steam does not install the Windows game from the library; the README explains how to
   [get the files through the Steam console](https://github.com/lukassolvar/opensow#getting-the-game-files-on-macos-and-linux).
2. Start OpenSOW:
   - **macOS**: open the `.dmg`, drag **OpenSOW** to Applications and start it from there.
   - **Windows**: unpack the `.zip` and start `OpenSOW\opensow-launcher.exe`.
   - **Linux**: unpack the `.tar.gz` and start `OpenSOW/opensow-launcher`. The launcher adds OpenSOW to your desktop's
     application menu.
3. In the launcher, click **Find games automatically** (or **Locate game…**), then **Play**.

The programs are not signed with a paid certificate yet. On macOS, if it says OpenSOW cannot be opened, click
**Open Anyway** under System Settings → Privacy & Security once. On Windows, choose **More info → Run anyway** if
SmartScreen warns. Later versions arrive through the launcher's own update.

## Known limitations

- No network play yet; skirmish is against the computer.
- Polish, Hungarian and Russian copies of the game run with English menus.
- A few details are not yet checked against the original: how a building looks while it is being destroyed, and some
  of Warmonger's mission-number rules.
- Unit pathfinding uses a simplified version of the original's grid, so units can occasionally take a slightly
  different path.
